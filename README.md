# Hugging Face Flashcard Generator

A Python-based flashcard generator using Hugging Face InferenceClient.

## Features

- Generates 5 study flashcards
- Accepts a topic from the user
- Uses Hugging Face Inference Providers
- Measures model response time
- Compares two different AI models

## Models Tested

1. meta-llama/Llama-3.1-8B-Instruct
2. deepseek-ai/DeepSeek-R1

## Topic Tested

Computer Networks
artificial Inteligence
machine learning
